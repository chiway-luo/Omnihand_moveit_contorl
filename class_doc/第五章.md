# 第五章 构建驱动与MoveIt的桥接功能包

## 创建功能包
```bash
cd src/hand_test
ros2 pkg create hand_control --build-type ament_cmake --dependencies rclcpp omnihand_node_msgs std_msgs sensor_msgs  --node-name hand_control
```

## 代码实现
- 代码内容详见hand_control功能包中的src/hand_control.cpp文件,这里不再赘述,主要实现了以下功能：
- 订阅moveit规划出的关节轨迹消息
- 将轨迹消息转换为电机控制指令
- 发布电机控制指令到底层驱动节点
- 订阅底层驱动节点发布的真实关节状态
- 将真实关节状态发布到/joint_states话题,供moveit和rviz使用
